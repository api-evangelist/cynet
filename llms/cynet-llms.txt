# Cynet

> Cynet is a unified, AI-powered cybersecurity platform for MSPs and lean IT/security teams that consolidates endpoint (EDR/EPP), network, email, cloud/SaaS, mobile, and identity protection into a single agent and console. It exposes a REST API (Cynet 360) for programmatic access to alerts, hosts, remediation, scans, and account operations, in an On-Prem V1 and a SaaS V3 track, authenticated with a tenant-scoped access token.

## APIs

- [Cynet 360 API (SaaS V3)](https://help.api.cynet.com/docs/API-V3/9g00cv3m8b10g-cynet-api-documentation): REST API for the Cynet 360 SaaS platform; alerts, hosts and host groups, remediation, scans, account/token. Base URL is tenant-specific (https://{tenant}.api.cynet.com).
- [Cynet 360 API (On-Prem V1)](https://help.api.cynet.com/docs/cynet/iah0dsbmetd0e-welcome-to-cynet-api-reference): REST API for on-premises Cynet 360 deployments.

## Authentication

- [Authentication](https://help.api.cynet.com/docs/cynet/b6b6c2d4906e9-authentication): Access-key + secret-key credential exchange at POST /api/account/token returns a bearer access token valid for 60 minutes, presented as a header on every request. Requires an API user with the Cynet API User permission (or an "API - full access" role).
